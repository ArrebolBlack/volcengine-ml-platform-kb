# 火山云机器学习平台知识库

帮助人和实验 agent 使用 veMLP 开发机、自定义任务、镜像、vePFS 与 TOS。
命令行工具名是 `volc`；`vloc` 是常见误拼。

先选择一个入口，按需读取一到两篇主题；不必加载整个知识库。

| 要做什么 | 入口 |
|---|---|
| 准备工具、创建任务、查日志、制作镜像或传输数据 | [平台文档](docs/INDEX.md) |
| 编写任务 YAML | [任务示例](examples/INDEX.md) |
| 在具体机构使用平台 | [机构说明](institutions/INDEX.md) |
| 检查知识库或提交维护改动 | [维护工具](scripts/INDEX.md) |

平台知识由本库维护；实际镜像、队列、任务配置、训练入口和实验结果由各项目维护。
真实凭据保存在系统凭据库或本机私密配置中，不进入知识库、任务示例或镜像。

本库以 2026 年 6—7 月使用经验重构。2026-09-19 对现有 Linux 安装的
`volc/1.2.55`、`tosutil v4.1.7` 做了帮助及原生模板核查。
这些检查不等于真实任务运行验证；各主题明确记录证据范围。

接入其他项目只需在项目资源文档中注明本库 checkout 路径，再链接所需主题。
跨机器部署时克隆同一仓库并更新入口位置，不复制整套平台文档。
实际远端地址由维护者配置，本库不预设托管平台。
