# Zenith 平台入口与 Agent 快速开始

Zenith 是 `10.1.130.101` 上的多云算力集成平台，接入火山 MLP、天翼 BC、无问、百度百舸等资源。
它有自己的账号、资源所有权、配额、目录和个人 API；本库原有 `volc`/veMLP 文档不能直接替代它。
从 Zenith 创建的资源按 Zenith 工作流操作；公网火山控制台或 `volc` 创建的旧资源不自动归入“我的”。

## 从哪里进入

- [控制台：我的总览](http://10.1.130.101/my)
- [帮助中心](http://10.1.130.101/help/)：支持搜索按钮或 `Ctrl+K`，按专题定位。
- [计算与连接](zenith-compute.md)：开发机、SSH、训练、DDP、回收、推理。
- [数据与资产](zenith-data.md)：镜像、模型、持久存储、文件与迁移。
- [账户、API 与管理](zenith-account-admin.md)：权限、项目、卡时、Token/CLI、管理员功能。

其他 Agent 从 [平台文档索引](INDEX.md)进入，只读本次需要的主题；本机 checkout 位置由接入项目
资源文档记录。实际实验镜像、配置、任务 ID、结果归使用方项目，不复制到本库。

## CLI 与 Codex 能做到什么

**当前不能仅靠官方 `zenith` CLI 完整操作平台，也不能声称已实现全平台无网页操作。**
个人 HTTP API 可补齐开发机和训练创建；系统 SSH 可用于本人开发机内的命令、代码和文件。
这条组合路径具备常规研究自动化的接口基础，但尚未完成本库的端到端实测。
实例删除、平台原生训练日志、资产管理等仍缺已公开的个人 API；完整覆盖表、接入前提和
非交互 SSH 方法见[账户与 API](zenith-account-admin.md)。不要套用原生 `volc` 命令或 AK/SK。

Agent 开始命令行接入时，依次确认：实际受支持的 HTTPS origin 和 Token → 查询本人身份、
项目、额度、规格/镜像及当前 schema → 按任务选择 API 或官方 CLI → 在已授权的本人资源上验证
SSH、挂载和输出。官方 CLI 另需可信 Release 包和受支持的运行环境；HTTP API 不依赖安装 CLI。
当前 Windows 宿主能找到 Node.js 24 和 OpenSSH，但找不到 `zenith` 命令，尚未验证任何带凭据请求。

## 控制台最短启动路径

1. 在能够打开上述内网地址的浏览器中访问控制台，核对右上角账号和身份。此轮使用已有 Chrome
   登录会话成功访问；没有重新验证密码/钉钉登录，也没有确认具体 VPN 或校外接入方案。
2. 打开“组织与项目”，确认组织分配的规格和存储开关、有效项目关系；打开“我的总览”看当前
   周期、剩余额度和资源区创建能力。组织和项目是独立关系，组织成员不自动获得项目目录。
3. 在“SSH 密钥”登记自己设备的公钥；已有密钥先核对，不重复生成或扩大访问。具体步骤见计算页。
4. 交互调试：我的开发机 → 创建开发机 → 型号/单机卡数 → 镜像/资源区 → 可选项目 → 一般优先级
   → 核对自动存储路径。需要个人高速目录时选择明确支持的区，不仅凭“自动分配”推断会挂载。
5. 提交后先等记录出现、运行中、连接信息/公钥就绪；复制页面 SSH 命令或打开可用终端/应用。
   检查真实挂载后，才把代码、环境、数据和输出放入持久目录。
6. 批量训练：先在目标环境验证入口，再“我的任务 → 新建训练任务”，选择标准任务、镜像、
   每 Worker 卡数、Worker 数及有效项目；核对总 GPU、挂载和 checkpoint。分布式模板见计算页。
7. 观察状态与真实日志，完成后验证输出可读取，再按任务授权停止/释放。网页成功提示只证明请求接受。

在已授权的 Linux 开发机上可做以下最小环境检查；这些是操作建议，**此轮未执行**：

```bash
hostname
pwd
nvidia-smi
findmnt -T /personal_fast_storage
df -hT /personal_fast_storage
python -c 'import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.device_count())'
python -c 'import torch; x=torch.arange(1024, device="cuda"); print((x*x).sum().item())'
```

上述挂载命令按本次页面实际路径替换；确认 `findmnt` 返回的来源与预期持久卷一致，不能仅看目录存在。
最后一条只验证很小的真实 GPU 运算，不代表训练或多卡性能验收。项目目录使用页面实际路径，
不要复制他人的登录名、工号或原生 vePFS 子路径。大任务前按实际工作负载检查所需模块及少量输出读写。

账号当时无开发机或训练任务，因此没有实际生命周期、SSH、挂载读写、镜像构建、训练或迁移验收。
没有提交 GPU 创建、删除、共享、Token 创建、凭据或权限变更。下述“实见”仅对应此时间和账号。

2026-09-26 重新读取个人 API/CLI、工作台、连接、训练和存储帮助，并成功以无凭据 HTTP GET
取得 [OpenAPI](http://10.1.130.101/pt/api/openapi.json) **2.0.1**，核查其全部 29 个路径、31 个操作。
无凭据访问 capabilities 返回 401 `unauthorized`；这证明服务可达，不证明用户认证或资源操作成功。
本轮未安装 CLI、创建 Token、提交算力或执行 SSH；也未重新浏览全部控制台表单。

**仍需要实际操作经验，至少完成下面三个小闭环，才能把“文档可用”提升为“Agent 可直接复用”。**

1. 接入与读取：取得受支持 origin、最小必要 Token 和可信 CLI 发布包；核对实际版本、身份、scope，
   跑通目录查询及分页。若只走 HTTP，可先验证 API，无须等待 CLI 安装。
2. 本人短时开发机：确认自动挂载计划 → 创建/连接 → 非交互 SSH → 小文件上传、读回和 GPU 小运算
   → 停止/启动后再核对持久数据与端点 → 按已授权方案收尾。停止与删除/释放分别验收。
3. 极短单卡任务：代码就绪 → 提交 → 跟踪回执和真实状态 → 取得日志、退出结果及持久产物，
   再验证一次取消到终态。当前最缺自动取回日志和产物的可执行路径。

测试只使用明确授权的资源范围；成功后将可复用命令及厂商限制补回对应主题，实验 ID、耗用和结果
留在使用方实验记录。多节点 DDP、镜像构建、迁移和抢占恢复另按真实需求验证，不能由单卡成功推导。

## 已知差异

| 差异 | 后续 Agent 应如何使用 |
|---|---|
| FAQ仍描述选择厂商/区域/队列；现有普通用户表单是逻辑规格和资源区 | 原生厂商/队列由平台管理；不套管理员专业向导 |
| 旧文档允许勾选挂载/公网 SSH，实见开发机自动配置 | 看实际预览；开关禁用不是点击失败，手动挂载由总管理员处理 |
| 帮助泛称公共池每区 512 GiB，实见区 5/10 为 2048、区 6 为 512 | 配置容量以当前存储页为准；不把旧数值当全平台上限 |
| 帮助训练描述存储开关，实见本次表单无该区块 | 核对自动挂载配置，在已授权短任务中验证读写，见计算页；不能继承开发机路径假设 |
| 新学生三档周额度、无项目低优、整节点预留 | 文档明确尚未全部上线；以当前有效策略/可见入口为准，详见账户页 |
| 旧权限页说 Token 无细粒度 scope | 较新的个人 API 契约已有 scope、过期和开关控制；手动挂载 scope 已移除，见账户页 |
| 9 月 22 日浏览器访问 schema 被拦截，9 月 26 日无凭据 GET 已成功 | 使用当前 2.0.1；认证和资源操作仍未验收 |
| 帮助尾部仍写 2.0.0/区 1–6，当前 schema 已有区 10 | 参数范围按 2.0.1；挂载字段的内部冲突见账户页，不猜实际接受行为 |

不把瞬时余卡、已用容量、余额或排队状态保存在本知识库；执行时重新读取。
导航、表单字段以当前界面为准；接口参数以当前 schema/具体契约为依据，实际响应用于确认服务行为。
权限和资源效果不能仅凭按钮判断；契约内部冲突单独标明，未经验证不选有利解释。
帮助声称曾完成某些厂商验收，不等于本轮亲测或当前用户可用。

## 先诊断再重试

| 现象 | 最先检查 |
|---|---|
| 无入口/按钮禁用 | 平台角色、产品身份、项目关系、本人所有权、厂商能力；不要仅凭按钮存在认定授权 |
| 资源区有卡但创建失败 | 单机碎片、落点池、规格、总提交/运行配额、卡时、镜像/存储约束；快照不预留 |
| 请求超时或列表未出现 | 先刷新与查询原操作；不要改名重复创建，也不要自动切区创建第二份 |
| 有目录但文件消失/不互通 | 实际挂载来源、资源区、池和个人卷；同路径不同区不是同一数据 |
| 无承载开发机 | 检查平台承载服务或自己运行机是否真实挂载且可达；重新检测；对象桶不需个人开发机 |
| SSH 失败 | 运行态、厂商 ID、端点可达、公钥注入、对应私钥；内网地址不能当公网用 |
| “已完成”但无结果 | 真实程序退出/日志、输出路径、文件可读与指标；完成状态不代表科学验收 |
| 余额低/查询失败 | 先看包内/按量/未知徽标；包内不耗现金，接口失败不等于余额零 |

需要反馈时带页面、操作时间、资源名称和厂商 ID、身份/项目、期望、完整脱敏错误；
从右上角“提交反馈”提交后可在“我的反馈”跟踪。不得附密码、私钥、Token 或临时签名 URL。
